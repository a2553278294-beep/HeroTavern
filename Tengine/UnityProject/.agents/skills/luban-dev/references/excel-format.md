# Excel 源数据

读取现有 workbook 的实际 Sheet 和标记行，不假设“固定前四行”。
常见标记为 `##var`、`##type`、`##`、`##group`；额外注释行和纵表会改变数据起点。
`__tables__`、`__beans__`、`__enums__` 是定义表，不按业务行表的列格式处理。

- 保留 Sheet 名、表头、批注、公式和非目标单元格；不要把整个 workbook 重建为纯值表。
- 明确主键、可空、空字符串、0、false 的差别。Excel 数字精度不足的长 ID 先确认存储约定。
- 容器与 Bean 的分隔符来自类型/schema，不能普遍将中文逗号替换后认为合法。
- group 是业务选择，不根据 icon/hp 等字段名默认判断。
- 纵表、多行列表、变体需针对该结构测试 helper 支持情况；不支持时停止自动批量改写。
- 修改后重新读取目标记录、检查引用、validate 并执行真实导出。

商业数据表的视觉或复杂格式维护可用专门表格工具，但本项目数据契约与生成验证仍以本技能为准。
