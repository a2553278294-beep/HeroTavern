## Q 版命名

主图：`character_c_<动作>_<部位>_<两位编号>_<方向>_<帧序号>.png`。

Mask：`character_c_<动作>_<部位>_<两位编号>m_<方向>_<帧序号>.png`。`m` 紧接部件编号，不能改成旧版的 `_m` 后缀。

例如，`character_c_idle_body_01_a_1.png` 对应 `character_c_idle_body_01m_a_1.png`。

| 动作 | 方向标记 | 每方向帧数 | 单张尺寸 |
| --- | --- | --- | --- |
| `idle` 待机 | `a`、`b`、`c`、`d` | 2 | 256×256 |
| `walk` 行走 | `a`、`b`、`c`、`d` | 4 | 256×256 |
| `sit` 坐姿 | `a`、`b`、`c`、`d` | 2 | 256×256 |

本批每个动作均包含 `body_01`、`face_01`、`hair_01`、`hair_03`，共 128 张主图和 128 张 Mask。按数字帧序号播放，同帧各部件与 Mask 使用同方向、同帧号。方向字母沿用原文件；本说明不推定其上下左右含义或播放速度。

本批整体替换此前 16 张 `character_c_*.png` 图集，旧文件已从当前资源目录移除，并保存在修改前备份与 Git 历史中。

## 配置对应

`Excel/CharacterPart.xlsx` 的 `id` 保留不含扩展名的部件组名，`color_id` 保留文本配色序号 `01`—`06`。Q 版组名不含方向和帧序号，例如 `character_c_idle_body_01`；加载时在组名后拼接 `_方向_帧序号.png`，Mask 在部件序号后插入 `m`。

`counterpart_id` 沿用同部位、同编号的立绘与 Q 版对应关系。Q 版 `walk`、`sit` 对应同部位立绘的 `idle` 组。

## 后续目录

新增类型按需建立 `UI/`（界面素材）、`Environments/`（场景素材）、`Effects/`（特效贴图）和 `SourceArt/`（PSD、Aseprite 等可编辑源文件）。这些目录在对应资源首次交付时创建。
